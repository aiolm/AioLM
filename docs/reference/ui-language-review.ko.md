## 범위와 표현 원칙

`5728398`을 기준으로 앱의 한국어 문자열 목록(테스트를 제외한 62개 소스 파일, 2,726개 문자열), 화면별 번역 카탈로그와 실제 Windows 개발 앱을 점검했다. 내부 자료 구조나 처리 단계를 그대로 보여 주는 안내는 현재 상태, 사용자에게 미치는 영향, 다음 행동을 설명하도록 수정했다. 관련 영어·일본어·중국어도 함께 검토했다.

## 보존하는 정보와 계약

- 엔진의 옵션명, 명령어, 파일 형식, JSON Schema, API 경로, 모델 아키텍처, 버전과 식별자는 실제 입력과 진단에 필요한 정확한 표기를 유지한다.
- 도움말 확인은 모델·API 호환성 확인과 구분한다. 미확인 정보, 저장한 값의 보존, 실행 전 확인, 적용·저장·재시작 시점은 쉬운 표현으로도 명확히 설명한다.
- 공통 런타임 표시의 번역은 화면에서만 적용한다. 기존 `runtimeLabel()` 결과와 런타임 원본 데이터는 변경하지 않으며, 앞으로 추가되는 알 수 없는 장치·설치 유형도 임의로 해석하지 않는다.
- 원본 엔진 로그와 진단, 지원 여부, 해시 검사, 취소·재시도 동작, 설정·프로필·이력 및 공개 API의 저장 형식은 이번 문구 정리의 변경 대상이 아니다.
- 단순 문구 일치를 확인하는 새 테스트는 추가하지 않았다. 기존 사용자 흐름의 기대 문구를 갱신하고, 새 표시 변환에는 원본 보존·알 수 없는 값·버전 구분과 실제 작성자 태그 보존 검사를 추가했다.

## 검증 기록

전체 프런트엔드 검사 204개 파일의 2,196개 테스트, 번역 검사, TypeScript 검사, 변경 파일 ESLint와 production 프런트엔드 빌드를 통과했다. 테스트 기대 문구를 갱신하는 과정에서 바뀐 테스트 이름을 원래대로 돌린 뒤 관련 24개 검사도 통과했다. 대량 옵션 테스트는 조회를 해당 도구 영역으로 좁히고 별도의 가시성 검증은 유지해, 기본 5초 제한을 늘리지 않고 통과했다.

Windows 개발 앱에서는 주요 메뉴, 엔진 등록 안내, 실제 Strata의 런타임→프로필→옵션 흐름과 채팅 안내를 확인했다. 설정 파일 전체와 프로필 7개·대화 8개의 해시가 변경 전과 일치했다. 원시 목록, 실패 원인 조사, 재검증 출력과 화면 기록은 커밋하지 않는 `tmp/strata-dev/app-language-*`에 보관한다.

개발 중 연속된 HMR 반영에서 오류 화면이 관찰됐으며, 포커스를 복원한 뒤 새로고침하여 정상 화면을 확인했다. 이 기록은 개발 앱의 재로딩 관찰이며, 이번 문구 수정으로 해당 HMR 문제를 해결했다는 판정은 하지 않는다. 설치 패키지·실제 추론·다른 운영체제 검증을 새로 수행했다는 의미도 아니다.

취소·오류·설치 진행 및 미래 미디어 종류는 모의 IPC와 합성 데이터로 검사했다. Windows의 실제 확인 범위는 기존 Strata의 런타임→프로필→옵션 이동, 메뉴·설정 안내와 저장 데이터 해시 보존이다. 정밀 검증의 네이티브 계산이나 새 설치 패키지 검증을 수행했다는 의미는 아니다.

최종 소스에서 전체 UI 검사 207개 파일의 2,235개 테스트와 TypeScript·네 언어 번역·런타임 유틸리티 검사, production 프런트엔드 빌드를 통과했다. 변경한 TypeScript 파일 33개의 ESLint는 오류 없이 통과했으며 `CustomSelect`의 기존 effect 의존성 경고 1개는 기준 커밋에서도 동일하게 확인했다. 빌드의 기존 청크 크기 경고도 유지했다.

최종 Windows 개발 앱에서는 기존 Strata의 런타임→프로필→옵션→닫기 흐름과 실제 옵션 플래그, 기본값·입력 형식 미확인 안내를 접근성 트리와 화면으로 재확인했다. 고급 설정의 삭제 범위 안내도 확인했으며 삭제·저장·초기화·추론은 실행하지 않았다. 채팅으로 돌아온 후 설정 파일 전체와 프로필 7개·대화 8개의 해시가 점검 전과 같음을 확인했다. 실패 재현과 원시 결과는 커밋하지 않는 `tmp/strata-dev/agy-language-*`에 보관한다.

## 옵션 초기화 범위 명확화

모델 설정 모달의 ‘전체 기본값으로 초기화’와 ‘런타임 옵션 기본값 복원’을 ‘옵션을 기본값으로 되돌리기’ 하나로 합쳤다. 프로필 선택과 옵션 조정 단계에서 같은 동작을 사용한다. 저장된 대화 지침과 편집 중인 지침은 모두 유지하며 모델·보조 모델·런타임·연결 설정도 바꾸지 않는다. 초기화만으로 저장하거나 엔진을 실행하지 않으며, 변경을 유지하려면 프로필을 명시적으로 저장해야 한다.

외부 엔진은 현재 확인한 옵션 범위에만 기본값 생략 규칙을 적용한다. 모델·연결용 옵션, 다른 명령 범위와 아직 확인하지 못한 기존 옵션은 유지한다. 엔진 도움말을 재확인해야 하는 동안에는 초기화를 막고, 해석할 수 없는 옵션 순서가 있으면 기존 값을 지우거나 성공으로 표시하지 않는다. 기본값을 숫자나 문자열로 추정해서 저장하지 않는다.

저장된 지침 및 공백·줄바꿈을 포함한 편집 중 지침의 초기화→저장→재열기, 기본값인 옵션과 비어 있지 않은 지침, 모델·연결 유지, 미확인 옵션·도움말·잘못된 순서에 관한 회귀 검사를 추가했다. Windows 개발 앱의 실제 Strata 컨트롤에서도 임시 지침 입력 후 두 단계에서 각각 초기화해 지침 유지와 단일 버튼을 확인했고, 검증용 변경을 버린 후 다시 열어 원래 값이 유지됨을 확인했다. 이번 실제 확인은 접근성 트리 기준이며 다른 창에 가려진 캡처를 화면 확인의 근거로 사용하지 않았다. 실제 저장·추론은 실행하지 않았고 설정 파일 전체·프로필 7개·대화 8개의 해시는 점검 전과 같았다.

전체 UI 검사 207개 파일의 2,244개 테스트와 TypeScript·변경 파일 ESLint·네 언어 번역 검사, production 프런트엔드 빌드를 통과했다. 저장·재열기 검사는 합성 저장소와 모의 IPC로 검증했으며 실제 사용자 프로필을 덮어쓰지 않았다.
