# 외부 엔진 모델 선택 후속 검증

2026-10-19, Windows 개발 앱 대상. 이전 Windows goal의 고정 production23 결과를 변경하지 않는 후속 결함 수정이다. 구현 source는 `77bf166`이며 계약은 [외부 엔진 모델 후보와 호환성](runtime-adapter-handoff.ko.md#외부-엔진-모델-후보와-호환성의-구분)을 따른다.

## 결함과 변경

외부 엔진의 미확인 모델을 내장 엔진의 호환성 필터로 숨겼다. 반대로 등록 manifest의 파일 형식이 같으면 같은 엔진의 다른 런타임까지 포함해 `partial`로 표시했다. 모델 목록은 전체 라이브러리를 먼저 탐색하고 모델마다 런타임 바이너리 무결성 검사도 반복했다.

선택한 런타임의 모델 바인딩을 먼저 표시하고, 다른 로컬 후보는 명시적으로 탐색한다. 바인딩은 비배타적 목록이며 직접 파일·폴더·배포 설정 경로를 입력할 수 있다. 외부 엔진의 카탈로그 결과는 `unknown`으로 유지한다. 후보 선택과 검증된 실행 가능성을 분리하고 기존 실행 전 실제 모델 probe, readiness, 무결성 및 프로세스 소유권 검사를 유지한다. 공통 코드에 Strata ID·모델 이름 분기는 추가하지 않았다.

Strata의 검증 revision은 `296b59d2f73c8f04a805df29c2fa97655adace78`이다. 해당 [고정 README](https://github.com/Niko1221/Strata/blob/296b59d2f73c8f04a805df29c2fa97655adace78/README.md)는 Qwen3.8-Flash-Next 및 그 파생·양자화 모델을 대상으로 설명한다. 임의 GGUF 전체를 지원한다는 근거로 사용하지 않는다. 실제 설치된 Coder 모델 revision은 `5348543e0147355ac9cbcb031184a3546350988e`, native engine SHA-256은 `c4709f17ef974ffa34af4f0c357160a89249cabf6e9a698fbe6d0dc65a3243fa`이다.

## 후속 OS 및 배포

Linux/Mac에서는 이 수정 이후 source로 외부 런타임별 바인딩 보기, 미확인 후보 탐색·직접 경로, 런타임 전환·취소·오류 복구, 해당 기기의 실제 지원 모델 probe와 추론을 재검증한다. 다른 OS의 공통 수정은 Windows의 해당 회귀 검사와 실제 모델 선택 흐름으로 연결한다. 이번 후속 수정의 새 production 설치 패키지 및 Linux/Mac 실제 검증은 수행하지 않았다. 이전 goal의 고정 production 검증과 이번 개발 앱 검증을 합쳐 기록하지 않는다.

## 외부 엔진의 고정 설정 분류 제거

`37a9a11` 이후 별도 후속 수정이다. 외부 엔진의 성능·메모리·생성·추론·보조 모델·고급 고정 탭을 제거하고, 런타임 옵션 한 화면에서 해당 설치의 공통 schema를 검색·필터링한다. 메타데이터의 그룹 이름이 앱의 기존 분류와 달라도 옵션을 누락시키지 않는다. AioLM의 대화 지침은 별도 화면에서 같은 프로필에 저장한다. 기존 링크는 유효한 화면으로 연결하며 내장 어댑터의 전용 편집기·API·저장 형식은 보존한다.

관련 UI 4개 파일 162개 검사, typecheck, 변경 TS/TSX ESLint가 **pass**다. 새로운 회귀 검사가 수정 전 외부 엔진의 8개 고정 탭 때문에 실패하고 수정 후 5개 공통 화면과 서로 다른 그룹의 옵션을 한 화면에서 확인했다. 실제 Windows Strata 개발 GUI에서도 5개 탭·옵션 검색·검토한 도움말 근거·`--ple-io`의 형식 미확인 텍스트 입력을 확인했다. 키보드 Down으로 대화 지침, Up으로 런타임 옵션 이동을 확인했다. 실제 화면 탐색 전후 전체 설정 파일과 프로필 7개·대화 8개의 해시가 같았다. 옵션 값·프로필·도움말 메타데이터를 저장하거나 실제 엔진을 시작하지 않았다. 진입 당시 이미 중지된 모델 상태를 유지했다.

이 변경은 frontend만 수정해 기존 개발 서버에 반영했다. 새 production 패키지나 실제 추론 재검증을 수행했다는 의미는 아니다. 원본은 `tmp/strata-dev/settings-tabs-*`에 보존하며 Linux/Mac 후속 검증에는 공통 화면·옵션 누락·키보드 탐색·기존 설정 보존 검사를 추가한다.

부가 관찰은 **fail(일시적 현상, 원인 미확정)**으로 별도 보존한다. 화면 검사 중 흰 화면과 설정 창이 닫힌 상태를 관찰했다. 이후 같은 설정·옵션 흐름을 반복하고 개발자 콘솔의 navigation 보존·verbose 로그를 확인한 구간에서는 재현되지 않았고 오류나 새로고침 기록도 없었다. WebView2 프로세스 교체는 확인되지 않았으며 설정·이력 해시도 그대로다. 원인이 제품·개발 환경·화면 관찰 도구 중 어디에 있는지 확정하지 않았다. 해결된 현상으로 보고하지 않으며, 다음 재현 시 navigation·console 로그와 같은 시점의 화면을 대조한다. 진단용 개발자 도구 설정은 원래 값으로 복원하고 해당 창만 닫았다. 마지막 실제 화면에서는 런타임 옵션이 정상 표시됐다.

## 빈 연결 탭 제거와 옵션의 기본 표시

`cbbaa53` 이후 사용자가 보고한 빈 연결 탭과 옵션 발견성의 후속 수정이다. 외부 엔진 화면을 모델·런타임 옵션·대화 지침·프로필의 4개 탭으로 정리하고 런타임 관리를 상단 선택기 옆에 둔다. 이전 연결 화면 링크는 옵션으로 연결한다. 옵션 표시가 관련 없는 런타임 전체 목록 검사와 함께 완료되도록 묶여 있던 대기를 제거하고, 외부 schema의 처음 64개만 표시하던 제한을 없앴다. 선택한 런타임의 실제 schema·파일 무결성 검사는 유지한다.

편집 가능한 전체 옵션이 미리보기 없이 표시되며 검색·그룹 필터를 사용할 수 있다. 앱 소유의 읽기 전용 인수, 명령어 가져오기·미리보기·도움말 검토는 아래의 접힌 도구 영역으로 옮겼다. 중복 옵션 제목과 지원 내용을 알 수 없는 외부 엔진의 빈 입력 요약도 제거했다. 예약·미확인 구문·민감 값 마스킹·검증 오류와 기존 프로필 저장 계약은 유지한다.
