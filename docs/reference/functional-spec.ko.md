# AioLM 기능 명세서

AioLM은 `llama.cpp` 기반의 로컬 AI 모델을 설치·실행하고, 채팅과 성능 측정을 제공하는 Windows x64 데스크톱 앱이다. 아래는 현재 저장소의 문서와 구현을 기준으로 정리한 주요 기능이다.

| ID | 기능 | 주요 동작 |
| --- | --- | --- |
| F01 | 모델 실행 | 지정 폴더의 GGUF 모델을 검색·조회·삭제한다. 모델 선택 후 같은 화면에서 런타임·프로필·컨텍스트·GPU 설정을 확인하고 실행한다. |
| F02 | 모델 다운로드 | Hugging Face에서 모델과 파일을 검색하고 다운로드한다. 진행 상태 확인과 다운로드 취소를 지원한다. |
| F03 | 런타임 관리 | CPU·Vulkan·ROCm·CUDA·SYCL·OpenVINO 런타임을 설치·선택·제거한다. ZIP 가져오기·내보내기와 출처 확인 후 PR 빌드 설치를 지원한다. |
| F04 | 서버·세션 관리 | 선택한 모델과 런타임으로 서버를 시작·중지하고 모델을 언로드한다. 여러 실행 세션의 상태를 조회하고 개별 제어한다. |
| F05 | 채팅 | 모델 응답을 실시간으로 표시하고 생성을 중지한다. 대화를 로컬에 저장하고 대화 생성·전환·삭제를 지원한다. |
| F06 | 첨부·문서 활용 | 이미지와 문서를 첨부하고, 문서 검색과 임베딩을 활용해 관련 내용을 대화에 반영한다. 이미지·임베딩 기능은 선택한 모델과 런타임의 지원 여부에 따른다. |
| F07 | 실행 설정 | 모델 실행 화면에서 주요 설정을 편집하고 상세 튜닝·LoRA·비전 설정을 펼쳐 사용한다. 튜닝 값을 개별 또는 전체 초기화하고 서버 설정 변경을 적용·재시작한다. 모델마다 마지막으로 저장한 런타임·GPU·튜닝·어댑터 구성을 복원한다. |
| F08 | 프로필·프로젝트 | 모델 실행 화면에서 공유 프로필을 생성·불러오기·저장·이름 변경·삭제한다. 서버·샘플링 프로필 선택은 모델별로 기억한다. 프로젝트별 설정과 연결 정보를 관리하고 프로젝트 JSON을 가져오거나 내보낸다. |
| F09 | 벤치마크 | `llama-bench`로 성능을 측정하고 진행 상태와 결과 이력을 확인한다. 실행 취소와 결과 CSV 내보내기를 지원한다. |
| F10 | API·게이트웨이 | 로컬 API 주소와 호출 예제를 제공한다. Anthropic 호환 및 Responses API를 제공하는 게이트웨이를 시작·중지한다. |
| F11 | MCP 연동 | MCP 서버를 등록·수정·삭제하고 도구 목록을 조회한다. 승인 정책에 따라 채팅에서 도구를 실행한다. |
| F12 | 진단·환경 설정 | 실행 상태와 진단 정보를 확인한다. 한국어·영어·일본어·중국어, 화면 테마, 서버 동작 등을 설정하고 환경 설정을 가져오기·내보내기·초기화한다. |

**기본 사용 흐름:** 모델 준비 → 모델 실행 화면에서 선택 → 런타임·프로필·설정 확인 → 실행 → 채팅 또는 API 사용. 필요한 런타임은 실행 화면의 ‘런타임 관리’에서 설치하고 돌아온다.

**주요 동작 조건**

- 모델·런타임 다운로드와 외부 서비스 연동에는 네트워크 연결이 필요하다.
- 서버 설정 변경은 적용 및 재시작 후 반영하며, 프로젝트 설정 적용은 서버가 중지된 상태에서 수행한다.
- 실행 중 다른 모델을 선택하면 중지 여부를 확인하며, 전환 후 새 모델은 직접 실행한다. 미저장 입력은 저장 또는 버리기 후 전환하며 잘못된 입력은 저장·실행을 막는다.
- 저장된 프로필은 공유하고 모델별 마지막 구성은 별도로 보관한다. 프로젝트를 명시적으로 적용하면 해당 프로젝트 구성을 우선한다. 설치되지 않은 런타임은 자동 대체하지 않고 재선택·설치를 안내한다.
- 튜닝 초기화는 선택한 런타임·모델의 기본값을 사용하도록 지정값을 제거한다. 모델 파일, 런타임 선택, GPU 배치, 어댑터 및 저장된 프로필은 유지한다.
- 현재 지원 플랫폼은 Windows x64이며, Linux와 macOS는 지원 계획에 포함된다.
