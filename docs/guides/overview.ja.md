# AioLM

> **言語:** [English](../../README.md) | [한국어](overview.ko.md) | [日本語](overview.ja.md) | [中文](overview.zh.md)

[ドキュメント一覧](../README.md) — インストール、使い方、リファレンス、セキュリティとプライバシーのポリシー。ドキュメントは現在のソースに基づくため、公開済みリリースには最新の変更がまだ含まれていない場合があります。

AioLM（All-in-One LM）は推論エンジンではなく、モデル・ランタイム・チャット・ベンチマークを管理する Windows/macOS/Linux 用デスクトップ GUI アダプターです。llama.cpp、Linux および Apple Silicon macOS（vllm-metal）の vLLM、Apple Silicon macOS の MLX、その他の接続済み OpenAI 互換エンジンを利用できます。互換性と制限事項は [推論ランタイム](../reference/inference-runtimes.md) を参照してください。

固定出力ベンチマーク（`openai-chat-serving@2`）には、出力長の制御とストリーミング出力トークン数の報告に対応したエンジンが必要です。全リクエストで選択したNトークンが報告された場合のみ成功とし、早期終了や検証不能は失敗にします。選択肢は1k・4k・8k・16k・32k・64k・128k・200kで、1k=1,024です。既定値は入力UTF-8 4096/16384 bytes、出力1k、同時実行数1/2/4、反復1回、ウォームアップ有効です。起動プロファイルとコンテキストは変更しないため、大きな出力にはモデルと各並列スロットに十分なコンテキストが必要です。従来の`@1`記録は上限方式のまま閲覧・書き出し・共有できます。[ベンチマークガイド](../reference/benchmarks.md)を参照してください。

モデルのロードと API サーバーの起動は独立しています。モデルをロードすると
アプリ内チャットで利用でき、外部アプリから接続する場合はサイドバーの
**APIサーバー**でサーバーを起動し、URL・キー・モデル ID をコピーして
OpenAI または Anthropic の例を選びます。モデルを切り替えたりメモリから解放したりしても
API サーバーは維持され、API を停止してもモデルとアプリ内チャットは利用できます。
詳しくは [API サーバーガイド](local-api.md) を参照してください。

## ワークスペース

- **ワークスペース:** チャット、プロジェクト。
- **モデル運用:** ライブラリ、検索、推論エンジン、ベンチマーク。
- **外部連携:** API サーバー、MCP サーバー。
- **アプリ:** 設定。

デスクトップのサイドバーはアイコン rail に折りたため、狭いウィンドウではナビゲーション drawer を使います。画面・テーマ・密度・フォントを切り替えても、開いている画面の下書きは保持されます。上部バーは既定の実行対象、チャットヘッダーの常時表示されるセッション選択はその会話に応答するセッションを操作します。worker を選んでも既定の対象は変わりません。検索用の埋め込みと音声・動画の前処理は会話設定にあります。

最大化したウィンドウではチャット本文・入力欄と各ワークスペースが利用可能な幅を使います。設定・API 画面・モデルのオプションは十分な幅があるときに複数列になり、各オプションの名前・説明・入力欄は同じまとまりに保ちます。モデル設定もウィンドウの幅と高さに合わせて広がり、狭い場合は列数を減らし、低い場合は内容をスクロールしながら下部の操作ボタンを利用できます。

モデル設定は **ランタイムを選択 → プロファイルを選択 → オプションを調整** の順です。ダウンロードやプレビューだけでは起動せず、プロファイルの保存と実行は別の操作です。プロジェクトも保存と保存済み設定の適用を区別します。テーマとフォントは **設定 → 外観**、密度は **一般** で変更します。

## 機能

- Hugging Face モデル検索（GGUF・safetensors・MLX の形式フィルターを任意で使用）と安全なモデル管理
- エンジン別の設定プロファイル、実行オプション、マルチモーダル入力（推論エンジンはモデル設定で選択）
- 推論エンジン管理（CPU/Vulkan/ROCm/CUDA/SYCL/OpenVINO ランタイムのインストール・管理）とポータブル ZIP 対応
- 番号/URL による PR ビルドと来歴レビュー
- ストリーミングチャット、ローカルスレッド、ドキュメントコンテキスト、埋め込み
- ユーザーの AGENTS.md 指示、ローカルスキル、アプリ内のパーソナライズ編集（[チャットのパーソナライズ](../reference/personalization.md)）
- プロジェクト、API サーバー、MCP サーバー
- 外部推論エンジンとの接続（[エンジンの自動接続](../reference/automatic-engine-connections.md)）
- サーバー/サンプリングチューニング
- 起動時の新バージョン通知と、設定からの検証済みインストーラーによる更新

**Discover**（Hugging Face 検索）は既定であらゆる形式のリポジトリを **Trending**（人気急上昇）順に表示し、必要に応じて GGUF・safetensors・MLX フィルターで絞り込めます。検索結果に表示されても、ダウンロードや実行に対応しているとは限りません。アプリは GGUF と完全な safetensors/MLX モデル一式を取得します。重みを選ぶと、そのモデルの構成・トークナイザー・必要な全分割を取得し、他のモデルや量子化版の重みは含めません。従来のモデル全体の取得も残ります。その他の形式は対応する外部エンジンで利用できます。Discover が推論エンジンを選んだり優先したりすることはありません。

ダウンロード中は速度と残り時間が表示され、**一時停止**できます。受信済みのデータは保持されるため、一時停止・失敗・アプリの終了で止まったダウンロードは **Discover → 一時停止中のダウンロード** に残り、**再開** で止まった位置から続けます。ダイジェストが公開されているファイルは、再開した場合も最初から最後まで検証します。モデルのダウンロード中も推論エンジンをインストールできます。ウィンドウを閉じると既定でシステムトレイに隠れ、**設定 → サーバー** でサインイン時に AioLM を自動起動するよう設定できます。

ロード中のモデルのセッション操作、ログ、実行設定は **ライブラリ** で確認できます。独立した診断ページやセッションページはありません。

モデル設定ダイアログのランタイム選択またはランタイム・GPU オプションから **推論エンジン管理** を開くと、選択中のエンジンに関係なく **すべての推論エンジンの一覧** が開きます。管理画面で特定のエンジンを表示していた場合も全体の一覧に戻ります。**モデル設定に戻る** を押すと、未保存のオプションと選択中のエンジン・ランタイムを保持したまま戻ります。**推論エンジン** は llama.cpp・vLLM・MLX などのエンジンの種類、**ランタイム** はインストール済みの実行環境を指します。

設定プロファイルと実行オプションについては [モデルの選択と設定](../reference/model-settings.md) と [サーバーオプション](../reference/server-options.md)（英語）を参照してください。

## プラットフォーム対応

Windows x64、macOS 13.3 以降（Apple Silicon・Intel）、Linux x86_64（Ubuntu 24.04 以降）のビルドを利用できます。Windows は NSIS/MSI、macOS は DMG、Linux は DEB/AppImage 形式です。**v0.2.1 から Linux パッケージも配布します。** [インストールガイド](install.ja.md#linux)を参照してください。macOS 13.3 以降向けの Apple Silicon（Metal）・Intel（CPU）DMG は **v0.3.0** から配布し、アドホック署名のみで公証されていません。[macOS のインストール](install.ja.md#macos)を参照してください。Linux ARM64 と NVIDIA DGX の環境はまだ確認されていません。リリースファイルは未署名で SHA-256 チェックサムが付属します。チェックサムはダウンロードしたファイルがリリースの一覧と一致するかを確認するだけで、公開者を保証するものではありません。

## ダウンロード

[Linux: DEB / AppImage](install.ja.md#linux)

Windows:

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://github.com/aiolm/AioLM/releases/latest/download/install.ps1 | iex"
```

または [GitHub Releases](https://github.com/aiolm/AioLM/releases) から最新のインストーラーを取得してください。

高度なインストールオプションとダウンロード検証は[インストールガイド](install.ja.md)、自分でビルドする方法は[ソースからビルド](install.ja.md#ソースからビルド)、CLI の使い方は [cli.ja.md](cli.ja.md) を参照してください。

既存データの移行と互換性は[移行ガイド](../reference/migration.md)を参照してください。
